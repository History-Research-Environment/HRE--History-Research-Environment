Configuración HRE

Esta pantalla le permite establecer una serie de preferencias sobre cómo funciona HRE. La configuración se puede cambiar en cualquier momento y no se ve afectada por el cierre y la reapertura de HRE o sus Proyectos.

1. Desde el menú principal HERRAMIENTAS, seleccione CONFIGURACIÓN, luego USUARIO para seleccionar y configurar un rango de opciones de Usuario.

2. Desde el conjunto de pestañas, puede elegir cambiar:

    HRE Look and Feel: para establecer el 'look and feel': el tema / tamaño y tipo de fuente (el predeterminado de HRE es Graphite, Blue-medium font, Arial)

    Configuración de idioma: para configurar los idiomas predeterminados para las pantallas, datos e informes de HRE

    Configuración de formato: para configurar los formatos de fecha y hora

    Opciones de usuario:

         Opciones de visualización
    • Para mostrar la pantalla de bienvenida al iniciar HRE (el valor predeterminado es No)
    • Para mostrar solicitudes de confirmación al cancelar y realizar otras acciones (el valor predeterminado es Sí)
    • Para recargar siempre el selector de personas cuando se añade una persona a la base de datos (el valor predeterminado es Sí). Si esta opción está desactivada, el Selector de personas solo se recarga cuando se solicita desde el menú de HRE
    • Para solicitar siempre el apellido de casada al guardar matrimonios (la opción predeterminada es No)
         Opciones del proyecto
    • Para abrir el último proyecto de HRE cerrado al iniciar HRE (la opción predeterminada es No)
    • Para realizar una copia de seguridad del proyecto al cerrarlo (la opción predeterminada es No)
    • Para habilitar el procesamiento de código de "plugin" (la opción predeterminada es No)
         Persona de referencia para relaciones
    • Si no hay ninguna persona de referencia seleccionada, Seleccionar persona permite especificar una persona de referencia para el cálculo de las relaciones que se muestran en la pantalla Administrar una persona
    • Si se ha seleccionado una persona de referencia:
         Actualizar relaciones permite seleccionar una persona de referencia diferente o actualizar las relaciones
         Borrar relaciones elimina la selección de la persona de referencia y desactiva la visualización de relaciones en la pantalla Administrar una persona

        Acentos: para establecer los colores de la fuente y el fondo para cualquier tema de HRE que desea definir

        Ubicaciones de archivos: para configurar las ubicaciones predeterminadas para proyectos, informes, copias de seguridad y copias de seguridad externas

        Opciones de depuración: para configurar la escritura de un archivo de registro (predeterminado), la escritura de mensajes de depuración y mensajes de tiempo. Estas opciones son principalmente para su uso por soporte técnico HRE

        Modo del Servidor: Para habilitar la ejecución de HRE en el modo Servidor (el valor predeterminado es No)
