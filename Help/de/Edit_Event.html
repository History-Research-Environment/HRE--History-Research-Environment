Ereignis hinzufügen/aktualisieren

Auf diesem Bildschirm können Sie ein neues Ereignis bearbeiten, bevor Sie es speichern, oder ein bestehendes Ereignis aktualisieren.

Die Bearbeitung von Elementen erfolgt über die Auswahlmöglichkeiten im Bedienfeld links.

Bitte beachten Sie, dass die Optionen „Flaggen“ und „Medien“ noch nicht verfügbar sind.

Datum: Hier können Sie das Veranstaltungsdatum und das gewünschte Sortierdatum eingeben.

Teilnehmer: Ein Rechtsklick im Bereich „Teilnehmer“ öffnet die Personenliste. Hier können Sie weitere Personen auswählen, die Sie der Veranstaltung hinzufügen möchten. Anschließend wählen Sie deren Rolle und geben gegebenenfalls weitere Informationen in einem Memo ein.

Ort: Im Bereich „Ort“ können Sie den Ortsstil auswählen und die Ortsdaten für die Veranstaltung eingeben.

Memo: Im Bereich „Memo“ können Sie beliebige Memo-Daten für die Veranstaltung eingeben.

Zitat: Zitate können Sie mit den Schaltflächen +/- hinzufügen oder löschen. Bestehende Zitate können Sie durch Doppelklicken auf den Eintrag bearbeiten. Sie können die Reihenfolge in der Liste mithilfe der Pfeiltasten (Auf/Ab) ändern.

Ereignistyp ändern: Mit dieser Schaltfläche können Sie den aktuellen Ereignistyp in einen beliebigen Ereignistyp DIESER EREIGNISGRUPPE ändern und die Rolle der betreffenden Person anpassen. Beachten Sie, dass bei einer Änderung des Ereignisses die Rolle bestehender Mitarbeiter gegebenenfalls an eine Rolle angepasst werden muss, die im neuen Ereignistyp verfügbar ist.

Satz-Editor: Mit dieser Schaltfläche können Sie den Satz bearbeiten, der für alle Rollen dieses Ereignistyps gilt.
