Add/Update Event

This screen allows you to edit a new Event before saving it or to update an existing Event.

Edit Items are controlled by selections in the control panel at left. Note that Flags and Media options are not yet available.

Dates: entries may be made for the event date and required Sort Date.

Associates: a right-click in the Associates panel opens the Person list and allows selection of further people to add to the event, followed by selection of their Role and any required Memo infomation.

Location: the location panel allows for selection of the Location Style and entry of location data for the event.

Memo: the Memo panel allows entry of any memo data for the event.

Citation: citations may be added or deleted by use of the +/- buttons and existing citation edited by double-clicking on their entry. They may also be re-ordered in the list by use of the up/down arrow buttons.

Change Event Type: use of this button allows the current Event type to be changed to any event type OF THIS EVENT GROUP and to chanage the Role of the subject person. Note that if the Event is changed, existing Associates may need to have their role changed to a role that exists in the new Event type.

Sentence Editor: use of this button allows edting of the sentence applying to any roles of this event type.
